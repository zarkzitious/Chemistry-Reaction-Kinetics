# Chemical Reaction Kinetics Analysis

## Overview
This project analyzes chemical reaction concentration data to investigate reaction kinetics and develop a predictive model.

## Objectives
- Analyze concentration data over time
- Apply logarithmic transformation to concentration
- Use linear regression to determine reaction kinetics
- Calculate the reaction rate constant
- Evaluate model accuracy using R²
- Compare experimental and predicted concentrations

## Methods
The concentration data was transformed using:

ln(C)

A linear regression model was then applied to determine the reaction rate constant and regression parameters.

## Results
- Rate constant (k): 0.09888 min⁻¹
- R²: 0.99967
- Initial predicted concentration: 0.9956 mol/L

The high R² value indicates that the regression model closely represents the experimental concentration data.
